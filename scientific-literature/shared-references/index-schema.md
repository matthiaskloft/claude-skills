# `_index.json` Schema

Each top-level key is a citekey.

```json
{
  "citekey": {
    "title": "string",
    "authors": ["string"],
    "authors_str": "string",
    "year": 2026,
    "journal": "string",
    "doi": "string",
    "openalex_id": "string",
    "categories": ["string"],
    "source": ["string"],
    "pdf": "string|null",
    "apa7": "string",
    "added_at": "YYYY-MM-DD"
  }
}
```
